# web: Next.js panel

Next.js 14 (App Router), TypeScript strict, Tailwind 3, shadcn/ui (new-york, zinc), TanStack Query 5,
react-hook-form + zod, lucide-react, sonner, qrcode. All dependency versions are pinned exactly
(`.npmrc` has `save-exact=true`).

Part 1 covers the foundation, auth, app shell, shared components, and all admin, reseller and
settings pages. Part 2 adds the client portal, Send SMS, campaigns, messages/DLR reports, analytics
and dashboard charts (recharts 2.15.0), monitor, tester and API & SMPP (see "Part 2" at the bottom).

## Run

```bash
npm ci
npm run dev                      # http://localhost:3001  (rewrites /api/* and /v1/* to API_URL)
API_URL=http://api:3000 npm run build && npm start   # production, port 3001
npm run lint && npm run typecheck && npm test        # eslint, tsc --noEmit, vitest (unit + jsdom page smoke tests)
```

`API_URL` defaults to `http://localhost:3000`. **Next.js bakes rewrite destinations in at build time**
(`.next/routes-manifest.json`), so set `API_URL` when you run `next build`. Setting it only for
`next start` has no effect. Set `NEXT_OUTPUT=standalone` at build time for a standalone Docker
output.

## Conventions (follow these in part 2)

**API calls.** Never call `fetch` directly. Use `api.<group>.<fn>` from `@/lib/api`. Every function is
typed against `lib/api/types.ts`, so no `any` crosses the boundary. If you need an endpoint that is
missing, add it to `endpoints.ts` along with its types. Errors are thrown as `ApiError`
(`status`, `code` = contract `error_code`, `message`, `details`). Use `errorMessage(e)` for display.
Set-style endpoints (`GET/PUT …/routes`, `…/rates`, `…/connections`) return `{items}`. Wrap them with
`asArray()`.

**Queries.** Build keys with `qk` (`qk.messages.list(params)`). Every key starts with the resource
root, so `invalidate: [qk.messages.all]` refreshes everything of that resource. For lists, use
`placeholderData: keepPreviousData` so paging doesn't flash. The api caps `page_size` at **200** and
does not support sorting yet, so don't set `sortable` on columns.

**Mutations.** Always use `useApiMutation({ mutationFn, success, invalidate, onSuccess })`. It shows
the toast and invalidates queries. Pass `success: (data, vars) => string | null` for dynamic text
(`null` means no toast). Destructive actions go through `<ConfirmDialog>`. Use `reason` for
free-text justification and `confirmText` for type-to-confirm. When you await
`mutation.mutateAsync()` inside `onConfirm`, the dialog stays open on error.

**Tables.** Combine `useTableState({ filters: ["q", "status"] as const, prefix? })`,
`useQuery(..., t.params)` and `<DataTable state={t.state} onStateChange={t.setState} …>`. Columns use
`hideOnMobile` so tables stay usable at 400px. Cursor-paginated endpoints (`GET /api/messages`)
should pass a plain array as `data` and render their own "Load more" button. `Pager` only handles
offset pagination.

**Forms.** Define a zod schema and call
`useForm<z.input<typeof s>, unknown, z.output<typeof s>>({ resolver: zodResolver(s) })`, then
render with the `@/components/shared/form-fields` wrappers. Number inputs hold `number | null`.
Money inputs hold integer **micros** (`MoneyField` / `MoneyInput`), and conversion is exact, with
no floats. Display money with `<Money micros currency />` (up to 4 decimals). Shared schemas live
in `lib/validation.ts` (`msisdnSchema`, `senderSchema`, `cidrSchema`, `re2Schema`,
`smppPasswordSchema`, `passwordSchema`). Request bodies are validated `.strict()` by the api, so
send only contract fields.

**Auth & roles.** Under `(app)`, use `useSession()` to get `{ user, org, role, impersonating,
original_org }`. To add a page, put it in `NAV[role]` and `ROUTE_ACCESS` in `lib/nav.ts`. The shell
then hides it for other roles and shows a 403 state on direct navigation. The api still enforces
authorization. Use the `?org_id=` scope when an admin or reseller acts on a child, e.g.
`api.apiKeys.list({ org_id })`.

**Tokens.** Access and refresh tokens are kept in `localStorage` (synced across tabs) with an
in-memory copy. When the access token is within 30s of expiry, or a request returns 401, the client
refreshes once (single-flight: concurrent requests share one refresh, so the rotating refresh token
is spent once) and retries. If refresh fails, the session is cleared and the user goes to
`/login?next=…`. `POST /api/auth/password` revokes all sessions and returns a new pair, which the
settings page stores. Impersonation (`useAuth().impersonate(orgId)` / `stopImpersonation()`) swaps
the token pair, clears the query cache and goes to `/dashboard`.

**UI.** Use shadcn primitives from `@/components/ui/*` and Tailwind tokens (`bg-muted`,
`text-success`, `text-warning`, `text-destructive`). Badge variants are `success`, `warning`,
`muted`, plus the shadcn defaults. Dark mode uses the `class` strategy (next-themes). Every icon-only
button gets an `aria-label`. Pages use `<PageHeader title description actions back />`.

Charts follow one system: categorical slots 1-3 (validated for CVD in light and dark), reserved status
colors for outcomes (always with a text label), one y-axis per chart, 2px lines, bars ≤24px with
4px rounded ends, hairline solid grid, legend for ≥2 series, and a table view on every chart.

### HTTP API connections

Contract: `docs/providers/HTTP-CONNECTIONS-CONTRACT.md` (api details in `CONTRACTS-CHANGES.md`,
"http connections (api/web)"). Every form is driven by the engine catalogue
(`GET /api/connections/adapters`, `useAdapters()`); nothing about a provider is hard-coded.

```

                                        (create / PATCH merge), callback URL, NODLR label
lib/carrier-status.ts                   READY / ERROR badges + describeHttpError (plain words)
components/connections/http/
  http-connection-fields.tsx            AdapterSelect (by country, "Best effort" for LIKELY), AdapterInfo,
                                        HttpConnectionFields (credentials as password inputs, write-only on
                                        edit; settings by type; generic_http template example)
  http-connection-dialog.tsx            HttpConnectionForm (create/edit), EditHttpConnectionDialog, useAdapters
  http-tools.tsx                        TestSendDialog, ProviderBalance (refresh), DlrCallbackUrl (copy)
```

Used by `/routes/new` (row type "HTTP API"), the route Carrier status card (HTTP rows), `/connections`
(type column, SMPP / HTTP API create tabs) and `/connections/[id]`. Messages with `dlr_stat = NODLR`
read "Sent (provider gives no delivery report)". Tests: `lib/__tests__/http-adapters.test.ts`,
`__tests__/http-connections.smoke.test.tsx`.

Build-time env (optional): `NEXT_PUBLIC_API_BASE_URL` (base URL shown in API docs, default this
panel's origin, which proxies `/v1`), `NEXT_PUBLIC_SMPP_HOST` / `NEXT_PUBLIC_SMPP_PORT` (default the
panel's hostname and 2775).
